# 平台与曲库管理：首批实现

唯一管理入口使用已确认的 A 布局，React + Ant Design，本地打包图标与资源。删除原型横幅、版本切换、示例状态、平台描述段落与能力说明段落。原管理页功能已迁入新侧栏，旧 `/advanced` 书签跳转到「储存与下载」。旧 HTML、JS、CSS 和对应 DOM 测试已删除。

## 已接入

- 注册 QQ、酷狗、酷我三个适配器，返回平台能力与真实启用状态。停用保留已有账号；切换平台不重启正在播放的音源进程。
- QQ 复用已有凭据、QQ/微信扫码、验证/刷新与退出。搜索只返回歌曲资料，个人推荐复用已有 QQ 推荐服务。
- 酷狗、酷我复用已有 musicdl 搜索/解析，只保存可用音源返回的实际格式；不声称已支持其账号登录或会员权限。
- 宿主网关提供管理员目录管理；容器不挂载整个 NAS，也不读取宿主曲库数据库。首次扫描读取标签和内容校验，不移动既有文件。
- 独立 SQLite 索引区分歌曲与文件版本；可靠标签与时长一致的版本聚合，完全相同的副本单独标记；不同 Live、伴奏等标题保持独立。
- 默认版本用于管理页播放。每个文件有固定 ID，支持带 Range 的试听，调整默认值不会改变其他文件 ID 对应的字节。
- 曲库与详情页读取音频内嵌封面；支持 MP3、FLAC、MP4 与 Ogg 的常见图片标签，优先正面封面，当前版本缺图时尝试同曲其他版本。封面仅通过管理员宿主接口读取，不修改音频；搜索与推荐使用平台提供的封面。
- 回收站在所选音乐目录之外。移动前校验文件身份，跨目录复制后验证内容；恢复使用独占创建，不覆盖原路径已有文件。
- 扫描、下载、转换任务持久化；重复待处理任务合并；重启后标为中断，可手动重试。QQ 下载校验实际格式、码率和时长，已保存的同档位不重复下载；本地转换保留原文件。

## 当前边界

- 酷狗、酷我的扫码账号与个人推荐仍需分别接入并验证，当前登录弹窗明确说明这一状态。
- 本地目录中无可靠平台映射的歌曲，需要先搜索并选择正确版本，才可从平台重新获取音质。
- 尚未实现飞牛官方播放器内的音质按钮，也没有自动搬走用户的多音质文件来隐藏原生重复条目。管理页的默认版本只影响此页面播放。
- 默认版本变化只更新扩展的 `songs.preferred`，不会改动原音频或飞牛的歌曲记录。实机只读检查确认 `track.audio_file_id` 绑定一个文件，当前未验证到官方默认版本切换接口；重新扫描不会导入扩展偏好。后续原生联动须先实现可恢复的默认版本发布及歌单/收藏对账，再触发并确认扫描完成，不能将扫描请求成功等同于版本已同步。
- 新文件/移入回收站的结果由飞牛曲库扫描同步，当前管理页不会直接修改官方数据库、收藏、历史或已导入歌单。
- 没有永久清空回收站入口；未完成的文件操作保留恢复记录，不静默重复删除。

## 存储与回退

目录清单、文件与任务记录位于 `sources-data/console-library/catalog.sqlite3`。私有回收站位于同目录下的 `trash/`，运行时资源位于 `webui-service/static/console/`。前端源代码位于 `webui-service/console/`；打包与镜像排除 node_modules 和原型源码，NAS 安装无需 Node 包管理器。

生产更新沿用已有容器映射和 Unix socket 网关，不修改 nginx、网络或 Docker 配置。保留旧镜像与源文件备份；部署前后对环境配置、compose、QQ 凭据和歌单快照做完整性核对。

## 2026-10-22 音质与曲库交互

- 播放设置以全局默认音质和各渠道覆盖组织。渠道列表来自共享能力声明，已启用优先，未启用折叠；QQ/网易及各洛雪平台分别支持已接入的档位，musicdl 酷狗/酷我等单一返回格式标明实际音质，不展示无效档位。
